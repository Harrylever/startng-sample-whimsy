Four stops from your laptop to your own address on the street.

  1. STOP 1
    Build itAny static browser game: HTML, JavaScript, three.js, Phaser.
  2. STOP 2
    Push it to GitHubKeep the game in a public repository.
  3. STOP 3
    Publish itOne API call with your repo link, no key needed.
  4. STOP 4
    Approve it onceOpen the link you receive and your game goes live at its own subdomain. Every later push updates it.
